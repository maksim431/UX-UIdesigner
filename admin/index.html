открыть на сайте

1. счётчик Яндекс Метрики

Создайте счётчик на metrika.yandex.ru/add: адрес сайта — , остальное по умолчанию. Скопируйте номер счётчика (8–9 цифр) и сохраните его здесь — код подключится на всех страницах сайта.

2. доступ к цифрам

Чтобы видеть статистику здесь, нужен ключ Яндекса с правом только на чтение Метрики:

  1. Откройте oauth.yandex.ru/client/new → «Для доступа к API или отладки».
  2. Доступ: Яндекс.Метрика → Получение статистики, чтение параметров.
  3. Redirect URI оставьте как есть (oauth.yandex.ru/verification_code). Создайте приложение.
  4. Скопируйте ClientID приложения сюда и нажмите «получить токен» — откроется Яндекс, разрешите доступ и скопируйте показанный токен.
  5. Вставьте токен во второе поле и нажмите «подключить».

3. свои визиты

Подключите ключ доступа GitHub — кнопка «ключ» справа вверху.

как редактировать

  • Текст — кликните по нему и печатайте прямо на странице.
  • Enter — перенос строки внутри того же текста. Новые абзацы, блоки и поля создать нельзя — так структура страницы не сломается.
  • Выделите слова и нажмите Ж (или Ctrl+B) — жирный.
  • Картинка — кликните по ней (или по серой заглушке) и выберите файл. Большие картинки уменьшаются до 2560px по ширине.
  • Галочка «картинки — в обеих версиях» заменяет ту же картинку и на русской, и на английской странице.
  • Нажмите сохранить — изменения попадут на сайт через 1–2 минуты.

ключ доступа GitHub

Админка сохраняет изменения прямо в репозиторий сайта. Для этого нужен личный ключ GitHub — он хранится только в этом браузере.

  1. Откройте github.com → Settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → UX-UIdesigner.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Создайте ключ, скопируйте и вставьте сюда.

автоперевод на английский

Когда вы правите русскую страницу, изменённые фрагменты при сохранении переводятся и подставляются в те же места английской версии. Остальной английский текст не трогается.
