# Картинки кейса «Мой тигр»

Положите сюда файл с нужным номером — он появится на сайте во всех версиях (продуктовой и для бизнеса, на русском и английском).
Формат: `.jpg` или `.png`, пропорции 4:3, лучше 2130×1600 px и не тяжелее 500 КБ.
