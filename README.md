# Портфолио Максима — UX/UI-дизайн

Сайт перенесён с Framer на обычный HTML, CSS и JS без фреймворков и сборки. Файлы из репозитория раздаются как есть, поэтому GitHub Pages публикует сайт сразу после каждого изменения в ветке `main`.

## Страницы

| Файл | Что это |
| --- | --- |
| `index.html` | первый экран: прелоадер, вопрос и кнопки «да / нет» |
| `product/index.html` | продуктовое портфолио (кнопка «да») |
| `web/index.html` | портфолио для бизнеса (кнопка «нет») |
| `projects/scplab/`, `projects/foodbot/`, `projects/vici/` | кейсы продуктового портфолио |
| `projects/mytiger/`, `projects/mytiger-web/` | кейс «Мой тигр» (картинки пока заглушки) |
| `projects/scplab-web/`, `projects/foodbot-web/`, `projects/vici-web/` | те же кейсы простым языком, для бизнеса, с блоком «если сделать в нейросети» |

### Английская версия

Все страницы продублированы на английском в папке `en/` с той же структурой: `en/index.html`, `en/product/`, `en/web/`, `en/projects/<кейс>/`. Переключатель «ru / en» стоит в шапке рядом с «контактами» (на первом экране — в правом верхнем углу) и ведёт на ту же страницу на другом языке. Выбор запоминается: если посетитель выбрал английский, при следующем заходе первый экран сразу открывается на английском.

Если меняете текст на русской странице, поправьте его и в английской копии. Надпись «design» на первом экране английской версии набрана шрифтом Sedgwick Ave Display — это замена рисованной надписи «дизайн».

### Как устроена страница кейса

Весь текст кейса лежит в `projects/<кейс>/index.html` по порядку, как на телефоне: заголовок, «в этом кейсе», картинки, задача, решение, результат. Картинки стоят прямо среди текста (`<figure class="cs-fig">`). На экранах от 1200px скрипт `case-layout.js` переносит их в правую колонку в порядке атрибута `data-d`; на планшете и телефоне они остаются в тексте.

В кейсе «Мой тигр» вместо картинок пока стоят заглушки (`cs-fig__box--ph`) с подписью, что туда поставить; чтобы добавить картинку, замените заглушку на `<img>` как в других кейсах.

Картинки пока подгружаются с серверов Framer (`framerusercontent.com`). Если закроете проект во Framer, скачайте их в `assets/img/` и поменяйте ссылки.

## Где что лежит

- `assets/css/site.css` — все стили. Размеры по брейкпоинтам те же, что во Framer: Desktop ≥1920, 1200–1919, Tablet 810–1199, Phone <810.
- `assets/js/portrait.js` — анимированный портрет на первом экране.
- `assets/js/projects.js` — блок «мои работы»: закреплённые карточки, которые сменяют друг друга при прокрутке.
- `assets/js/page.js` — шапка и меню контактов, копирование почты, появление первого экрана, параллакс, переход по «посмотреть работы».
- `assets/js/smooth.js` — плавная прокрутка колесом мыши.
- `assets/js/case.js`, `assets/js/case-layout.js` — страницы кейсов: раскладка в две колонки, появление картинок, кнопка «наверх».
- `assets/js/aicompare.js` — блок «если вы решите создать продукт самостоятельно в нейросети» в кейсах для бизнеса.
- `assets/js/ui.js` — общее для всех страниц: ASCII-кнопки, меню контактов, копирование почты.
- `assets/js/cursor.js` — лёгкий ASCII-след за курсором (только мышь/тачпад).
- `assets/js/ascii.js` — ASCII-эффект на кнопках и пиксельные переходы между страницами.
- `assets/js/first.js` — прелоадер и переход с первого экрана.
- `assets/img/` — логотип, надписи «UX/UI» и «дизайн», карта яркости портрета.

## Как поменять тексты

Все тексты лежат прямо в HTML: подпись и описание на первом экране, проекты, контакты. Поменяйте текст в файле, сохраните изменения в `main`, и через минуту-две сайт обновится.

## Производительность

Портрет раньше перерисовывал всю сложную графику 60 раз в секунду: около 14 мс работы процессора на кадр, на экране Retina около 32 мс. Сейчас:

- штриховка силуэта считается один раз, на кадре подставляется готовым изображением;
- работа скриптов на кадр — около 0,3 мс, примерно в 50–100 раз меньше;
- 30 кадров в секунду вместо 60, на слабых устройствах — 20;
- анимация останавливается, когда портрет не виден или вкладка скрыта;
- подписи HUD сделаны обычным HTML;
- блок проектов и параллакс пересчитываются только при прокрутке, а не постоянно.

Если в системе включено «уменьшение движения», анимации отключаются.
